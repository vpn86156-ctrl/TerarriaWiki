# TERRA Wiki — Android APK

**Одно устанавливаемое Android-приложение с полным каталогом, сюжетом, дневником и новым оформлением. Не сайт и не PWA.** Работает без сервера и обязательного доступа к интернету.

## Скачать и установить

Текущий APK: `downloads/TERRA-Wiki-0.3.0.apk` (около 5,4 МБ). После сборки: `artifacts/TERRA-Wiki-0.3.0.apk`. Android 8.0+, minSdk 26, targetSdk 35. Нужен обновлённый Android System WebView.

**Устанавливай поверх «TERRA Дизайн» 0.2.0 без её удаления.** TERRA Wiki — новое имя того же приложения: сохранены package ID `io.github.vpn86156.terraletopis.design`, сертификат и ключ localStorage `terra:chronicle:v1`; versionCode повышен до 4. Старое название в техническом ID оставлено намеренно ради обновления. Разных сборок «дизайн»/«обычная» в текущем коде больше нет.

Для установки открой APK на Android и разреши установку для выбранного браузера/файлового менеджера, если система запросит. Это не публикация в Google Play. Подпись APK проверяется `apksigner`.

Историческая «TERRA Летопись» 0.1.1 имела другой package ID и другой ключ. Её записи не объединяются автоматически с TERRA Wiki. Не удаляй её, пока не сохранишь нужные записи: удаление приложения стирает его данные. Старые APK в downloads оставлены только для сохранности прежних ссылок, они не являются дополнительными обязательными приложениями.

## Новое в 0.3.0

- Название **TERRA Wiki** в лаунчере, интерфейсе и вступлении. Новая иконка: пиксельное дерево на травяном островке с открытой книгой, адаптивная маска Android и bitmap fallback. Это новая AI-generated иллюстрация, не официальный логотип Terraria.
- Внизу истории — **«Следующая история»** и **«Предыдущая история»**, номер страницы. Переход заменяет содержимое того же диалога, возвращает прокрутку и фокус к заголовку; окна не накапливаются.
- Закрытую историю можно прочитать наперёд только после явного согласия на спойлеры (или если общий режим без спойлеров уже выключен). Это **не проходит главы** и не меняет глобальный переключатель. На последней истории — переход к списку.
- Новый мир действительно новый: **0/11 глав, 0%, день 1, пустой рюкзак**. Главы завершаются только вручную с подтверждением.
- Старые сохранения с двумя стартовыми этапами не сбрасываются молча: можно оставить прогресс или подтвердить начало с первой главы. Сбрасываются только завершённые главы, дневник/ресурсы/избранное/имя мира/день сохраняются. Повторный сброс доступен в «Изменить мир и день».
- Сохранены космическое вступление с Лунным лордом, одна мягкая вспышка, орбиты и частицы, плавные вылеты карточек, подсветки и системный reduced motion. Повтор вступления — в «О приложении».

## Все функции в одном APK

- Ровно восемь разделов: Главная, Путь мира, Из моих ресурсов, Все крафты, Как получить, Все NPC, Сюжет Terraria, Мой дневник.
- 6186 предметов, 3655 рецептов, 3233 результата крафта, 26 основных NPC + 14 дополнительных.
- Локальные подлинные игровые атласы и изображения боссов; Manrope/Russo One. Источники — `ATTRIBUTION.md` и раздел внутри приложения.
- 11 этапов, последовательное прохождение, подтверждение, печать завершения, атмосфера мира и авторские истории Гида.
- Поиск RU/EN, фильтры, страницы по 48 предметов, варианты рецептов, дерево, количества/станции, источники получения и переход к ингредиенту.
- Инвентарь, проверка ресурсов с max-flow для пересекающихся групп, избранное, дневник CRUD и цели.
- Локальные сохранения между запусками. Нет регистрации, облачной синхронизации и автобэкапа. Очистка данных/удаление APK удаляет записи.

**Ограничения:** 5426 русских имён из игровых таблиц, 760 честных EN fallback-имён. Неизвестные шансы и цены не выдумываются. Некоторые дополнительные условия — на английском с отметкой EN. Счастье NPC приблизительное. Ветви дерева не распределяют общий запас между всеми соседями и могут сбросить раскрытия при вложенном диалоге; точная проверка пересекающихся групп выполняется по списку выбранного рецепта. Истории авторские, не официальный канон Re-Logic.

## Архитектура

Java Activity + React-интерфейс в **Android WebView**, не полностью нативные Android-экраны. HTML/JS/CSS, изображения и шрифты находятся внутри APK. `ui/index.html` — шаблон внутреннего интерфейса, не опубликованный сайт.

Activity перехватывает `https://appassets.androidplatform.net/assets/...` и читает assets APK напрямую. DNS/сервер/HTTP-загрузка не используются, другие запросы блокируются. INTERNET и разрешений файлов/камеры/геолокации/контактов нет. Файловый доступ WebView выключен, JavaScript bridge отсутствует. Внешние ссылки открываются после жеста пользователя/подтверждения в браузере. Android Back сначала закрывает диалог/меню, затем возвращает на главную и спрашивает о выходе.

## Сборка (Linux x86_64)

```sh
npm ci
npm run setup:android
# Перед подписанной сборкой восстанови приватный ключ 0.2.0/0.3.0:
# .android-signing/design-preview.p12 и design-preview-password.txt
npm run build
npm test
npm run test:ui
```

- `build:ui` создаёт внутренние assets в `build/ui`; `build:apk` — Java, DEX, ресурсы, выравнивание ZIP и подпись.
- SDK: Android API 35 JAR из Sable/android-platforms, D8 из yaap/prebuilts_r8 по фиксированным Git blob SHA с проверкой хэша. Нужны Python/pip и gh с доступом к публичным репозиториям.
- JRE 21.0.8.2 — jdk4py/PyPI. AAPT2, javac и официальный apksigner — npm devDependencies с integrity lockfile; в APK не входят.
- Android Studio: AGP 8.9.2, Java 17+, SDK 35; сначала `npm run build:ui`. Gradle debug использует другой ключ и не обновляет публичную подписанную сборку.
- Исходник иконки — `artwork/wiki-icon-master.png`, не попадает в APK; PNG для интерфейса и адаптивного лаунчера уже включены в исходники.

### Подпись и обновления

Приватные `.android-signing/design-preview.p12` и `.android-signing/design-preview-password.txt` исключены из Git и APK. Старое имя файла сохранено ради ключа опубликованной 0.2.0. **Сохрани их отдельно: рабочая среда не является надёжным хранилищем.** Не публикуй приватный ключ и пароль.

Можно задать `TERRA_KEYSTORE`/`TERRA_KEYPASS_FILE` (alias `terra`). Без ключа подписанная сборка останавливается, а не создаёт несовместимое обновление. С новым собственным ключом можно собрать APK для новой установки, но он не обновит опубликованный APK с другим сертификатом.

Контрольные суммы опубликованных файлов — `downloads/SHA256SUMS.txt`. Локальные `artifacts/SHA256SUMS.txt` и `apk-info.txt` — результат сборки. Ключи и промежуточные артефакты в Git не входят.
