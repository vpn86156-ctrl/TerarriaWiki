# Заброшка

Пиксельный рогалик для Android: ты спускаешься в заброшенный подвал, пробиваешься через
корпуса больницы и цеха завода, собираешь ключи, патроны и монеты, отбиваешься от зомби,
скелетов и медсестёр и в конце каждого этажа выносишь босса.

* **Жанр:** top-down roguelite, вид сверху.
* **Управление:** виртуальный джойстик слева; справа — УДАР, ОГОНЬ, ПЕРЕЗАРЯД, ГРАНАТА.
  На компьютере то же самое с клавиатуры: `WASD` — ходьба, `J` — удар, `K` — огонь,
  `R` — перезарядка, `G` — граната.
* **Три локации, 10 этажей:** подвал (3), больница (3), завод (4). На последнем этаже
  каждой локации — свой босс: СМОТРИТЕЛЬ, ГЛАВВРАЧ, НАЧАЛЬНИК СМЕНЫ.
* **Оружие:** лом, нож, топор; пистолет, дробовик, автомат; плюс гранаты.
  Огонь ищет ближайшего врага сам — прицеливаться пальцем не нужно.
* **Магазин между этажами:** аптечка, бронежилет, заточка, кроссовки, патроны, гранаты,
  новое оружие.
* **Офлайн:** APK не просит ни одного разрешения и не обращается в сеть.

## Сборка

```bash
npm install
npm run setup:android      # один раз: android.jar, r8, JDK
npm run setup:signing      # только если ключ потерян: создаёт новый в .android-signing
npm run build:apk          # dist + подписанный APK в downloads/
npm run test:apk           # проверка подписи, манифеста и содержимого архива
```

Ключ подписи **лежит в репозитории**: `.android-signing/zabroshka.p12` вместе с
`zabroshka-password.txt`. Так сборка остаётся воспроизводимой, а новые версии ставятся
поверх старых. Если ключ всё-таки заменить, старую версию игры придётся удалить с
телефона перед обновлением — Android не даёт обновить приложение, подписанное другим
ключом.

## Проверки

```bash
npm test                   # модульные тесты: контент, симуляция, рендер, ввод, звук, прогресс
npm run test:ui            # сквозные тесты интерфейса в Chromium (сборка + Playwright)
npm run test:apk           # проверка собранного APK
npm audit                  # зависимости
```

## Устройство кода

| Файл | Что внутри |
| --- | --- |
| `src/content.js` | локации, враги, оружие, магазин, подсказки — только данные |
| `src/engine.js` | симуляция: генерация уровней, бой, пули, взрывы, боссы (без DOM) |
| `src/render.js` | пиксельный рендер в кадре высотой 270 px, свет, мини-карта |
| `src/audio.js` | WebAudio: сэмплы CC0, музыка по ролям, синтезированный резерв |
| `src/input.js` | джойстик, кнопки, клавиатура |
| `src/progress.js` | сохранение прогресса и настроек в localStorage |
| `src/main.js` | экраны, HUD, игровой цикл, магазин, настройки |

Симуляция не знает ни о DOM, ни о браузере, поэтому уровни и бой проверяются обычными
тестами в Node: 12 зерен × 10 этажей проверяются на проходимость, спавн — на безопасность.

## Откуда графика, звук и шрифты

Графика рисуется процедурно, пиксель за пикселем: пол, стены, персонажи, боссы и иконки
собираются из палитр локаций прямо в `src/render.js`. Иконка приложения нарисована
нейросетью и переведена в пиксельный вид (`public/images/app-icon-*.png`).

Музыка и звуки — CC0 1.0 (общественное достояние), полный список с названиями треков и
паков лежит в `public/audio/manifest.json` и показывается на экране «МУЗЫКА И ЗВУКИ»
в самой игре. Подробности — в [ATTRIBUTION.md](ATTRIBUTION.md).

Шрифты Manrope и Russo One — SIL Open Font License 1.1 (тексты лицензий в `public/licenses`).
