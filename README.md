# Последний факел

Небольшая самостоятельная браузерная игра на русском языке. Исследуй три этажа подземелья, собери ключи и выберись наружу. Три необязательных тайника, циклические ловушки, преследующие стражи, источники здоровья и короткий защитный рывок.

**Играть:** https://vpn86156-ctrl.github.io/TerarriaWiki/

## Управление

- WASD или стрелки — движение.
- Пробел — рывок с короткой неуязвимостью. Перезарядка 1,8 секунды.
- E — открыть выход, проверить треснувшую стену или выпить воду.
- Esc — пауза. Смена вкладки также приостанавливает игру.
- На телефоне — крестовина и кнопки под игровым полем. Можно одновременно держать направление и нажимать рывок.

Собери **все ключи текущего этажа** и нажми действие рядом с воротами. Шипы предупреждают золотым цветом перед выдвижением. Стражей нельзя убить — избегай их. Источник восстанавливает одно сердце один раз за попытку; при полном здоровье не расходуется. Новый этаж восстанавливает здоровье. Поражение возвращает к началу текущего этажа и сбрасывает его ключи, но не время забега и не найденные печати. Перезапуск всего приключения обнуляет прогресс забега.

Только лучший результат завершённого забега и настройка звука сохраняются в `localStorage` этого браузера. Продолжение после закрытия страницы, серверные аккаунты и общая таблица рекордов не предусмотрены. Отказ в доступе к хранилищу не мешает игре. Звук по умолчанию выключен; его можно включить в шапке.

## Разработка

Требуется Node.js 22+.

```sh
npm ci
npm run dev
# http://localhost:4173 — сервер слушает 0.0.0.0, PORT можно переопределить
npm test
```

Runtime-зависимостей нет. Canvas 2D, ES modules, CSS и Web Audio API; без сборки и внешних шрифтов/сетевых ресурсов. Весь игровой рисунок создаётся кодом, без ассетов прежнего сайта. Статические файлы можно размещать как в корне, так и в подпапке.

### Браузерные проверки

```sh
npx playwright install --with-deps chromium
npm run test:browser
```

Для ограниченной Linux x64 среды, где нельзя установить системные библиотеки, предусмотрен отдельный runner с Chromium из npm:

```sh
npm run test:browser:sandbox
```

Результаты и снимки находятся в игнорируемой папке `test-results/`. Проверяются реальное движение до первого ключа, клавиатура, сенсорное управление, пауза, правила, перезапуск, переходы этажей, поражение/повтор, победа, сохранение рекорда и отказ `localStorage`. Переходы к концу этажей в браузерном тесте ускоряются тестовой инструментализацией; доступность всех целей и закрытость тайников дополнительно проверяются обходом карт в unit-тестах.

## Структура

- `src/engine.js` — карты, столкновения, ловушки, преследователи, видимость и состояние забега; без DOM.
- `src/render.js` — процедурный пиксельный рисунок, камера, освещение и мини-карта.
- `src/app.js` — UI, клавиатура/касания, звук и локальный рекорд.
- `scripts/serve.mjs` — локальный статический сервер.
- `sw.js` — только вывод из эксплуатации service worker прежнего сайта: удаляет исключительно старые кеши с префиксом `terraria-guide-v1-`, снимает регистрацию. Новая игра не регистрирует worker и не создаёт офлайн-кеш.
