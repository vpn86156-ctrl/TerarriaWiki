# Новый сайт

Старый сайт удалён. Оставлена пустая HTML-страница без выбранного стека или дизайна.

Git-история сохранена: прежний проект можно восстановить из предыдущих коммитов.

`sw.js` — служебный обработчик отключения прежней офлайн-копии. Он удаляет только
кэши `terraria-guide-v1-*`, снимает регистрацию старого Service Worker и переводит
открытые страницы на текущую версию. Прогресс в localStorage и чужие кэши не удаляются.
Для новых посетителей Service Worker не регистрируется.
