# Космопилот

Небольшая бесконечная космическая аркада для Android. Игра запускается в горизонтальном положении, работает без интернета и не запрашивает разрешений.

## Установка

Скачайте **[Kosmopilot-1.0.0.apk](downloads/Kosmopilot-1.0.0.apk)** на телефон и откройте файл. Если Android попросит разрешить установку из выбранного источника, разрешение можно выдать в настройках системы. Минимальная версия — **Android 8.0**; нужен актуальный компонент Android System WebView. Контрольная сумма файла находится в `downloads/SHA256SUMS.txt`.

## Как играть

- Зажмите левую часть экрана и ведите пальцем: корабль последует за ним. Пушка стреляет сама.
- Уворачивайтесь от астероидов и снарядов дронов. У корабля три деления корпуса.
- Золотые звёзды добавляют очки, зелёный крест восстанавливает корпус. Если корпус целый, крест даёт дополнительные очки.
- Кнопка **«Волна»** справа уничтожает опасности рядом и ненадолго защищает корабль; затем ей нужно 9 секунд на перезарядку. Её можно нажать вторым пальцем, не отпуская управление.
- Кнопка паузы останавливает полёт; в меню паузы можно завершить полёт. Рекорд и настройка звука сохраняются на устройстве. При удалении игры локальные данные тоже удаляются.

Для проверки в браузере можно управлять стрелками или WASD и нажимать пробел для волны. На телефоне предусмотрено сенсорное управление; Android-кнопка «Назад» вызывает паузу.

## Сборка

Исходники включают игровую симуляцию и интерфейс на Canvas/JavaScript, а также минимальную Android-оболочку с локальными ресурсами. Подключения к сети в приложении нет. Ниже приведены команды для Linux x86-64 с Node.js 20.19+ (ветка 20) или 22.12+, Python 3 с pip и `gh`:

```sh
npm ci
npm run setup:android     # скачивает закреплённый инструментарий в .local/
npm run setup:signing     # только один раз для нового ключа
npm run build:apk         # создаёт downloads/Kosmopilot-1.0.0.apk
```

Ключ подписи и пароль лежат в `.android-signing/` и не входят в Git или APK. **Сохраните оба файла в защищённом месте**: Android принимает обновление установленной игры только с тем же ключом. При потере ключа потребуется удалить старую установку вместе с её данными. Для существующего ключа можно задать `KOSMO_KEYSTORE`, `KOSMO_KEYPASS_FILE` и, при необходимости, `KOSMO_KEY_ALIAS`. Скрипт не создаёт замену ключу автоматически.

Проверки:

```sh
npm test                  # симуляция и правила игры
npm run build:web && npm run test:ui   # сенсорное управление, интерфейс и офлайн-загрузка
npm run test:apk          # подпись, манифест, локальные ресурсы, выравнивание и хеш
```

Браузерный предпросмотр для разработки: `npm run build:web && npm run preview`. Это только предпросмотр той же игры, а не отдельная PWA или онлайн-сервис. Сведения об изображениях и шрифтах — в [ATTRIBUTION.md](ATTRIBUTION.md).
