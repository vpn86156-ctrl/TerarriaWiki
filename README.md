# Последний факел · Экспедиция 2

Русскоязычная браузерная игра: три одиночных этажа, скрытые комнаты, ловушки и преследователи. Теперь с установкой на домашний экран, офлайн-одиночкой, коллекцией и отдельным сетевым кооперативом на двоих.

**Статический сайт:** https://vpn86156-ctrl.github.io/TerarriaWiki/

## Что нового

- PWA: manifest, обычные/maskable PNG-иконки, Apple touch icon, кнопка установки с инструкциями для iOS/Android/ПК. Установка доступна на HTTPS (или localhost) в поддерживающем браузере. В Safari iOS используется «Поделиться → На экран Домой».
- Service worker кеширует только собственную оболочку. После первой успешной загрузки одиночная игра и коллекция доступны без сети. Новая версия предлагает обновление, а не перезагружает текущий забег самостоятельно.
- Никакого выделения текста, перетаскивания и меню копирования при удержании игровых кнопок. Поля имени, кода комнаты и адреса сервера остаются редактируемыми.
- Горизонтальный режим на телефоне: слева крестовина, справа действия, игровое поле между ними. Не требует поддержки блокировки ориентации. Кнопка ⛶ включает fullscreen, если браузер позволяет; выйти можно ею же.
- Анимация шага, плащ, след рывка, частицы предметов/урона/щита, анимированное открытие кейса. Учитывается `prefers-reduced-motion`.
- Искры ускоряют на 18% на 4 секунды. Маяк замедляет стражей на 7 секунд; активируется действием один раз за попытку этажа. Стражи на поздних этажах быстрее.

## Управление и прохождение

WASD/стрелки — движение, Пробел — рывок, E — действие, Esc — пауза. На телефоне используются кнопки. Собери все ключи этажа, подойди к выходу и нажми действие. Источник лечит одно сердце и не расходуется при полном здоровье. Треснувшие стены скрывают необязательные печати.

Гибель сбрасывает текущий этаж, а не всё приключение. Время и найденные печати сохраняются внутри забега. Закрытие вкладки прерывает забег. Монеты, экипировка, коллекция, настройка звука и лучший результат сохраняются локально; аккаунтов и облачной синхронизации нет. Отказ в доступе к хранилищу не блокирует игру, но сохранение тогда недоступно.

## Монеты, кейсы и экипировка

Награда начисляется **при успешном выходе с этажа**, один раз за этот этаж текущего забега:

| Условие                             |      Монеты |
| ----------------------------------- | ----------: |
| Этаж                                |          60 |
| Последняя попытка этажа без ранений |         +20 |
| Каждая собранная искра              |          +5 |
| Найденная печать этого этажа        |         +25 |
| Завершение всех трёх этажей         |        +100 |
| Сетевое испытание                   | 120 каждому |

Кейс стоит 100 игровых монет. Денежных покупок нет. 18 предметов: два стартовых и 16 из кейсов (по 4 каждой редкости). Шансы редкости: обычная **60%**, редкая **25%**, эпическая **12%**, легендарная **3%**. Внутри редкости предметы равновероятны. Для выбора используется `crypto.getRandomValues`. За дубликат возвращаются 15 / 30 / 60 / 100 монет соответственно. Награда записывается до анимации, поэтому закрытие окна не отнимает выпавший предмет.

Одновременно надеты один скин и одни ботинки. Эффекты: скорость, радиус света, перезарядка рывка или щит от одного удара на каждом этаже. Бонусы ограничены и фиксируются в начале этажа/новой попытки, поэтому смена вещей посреди прохождения не восстанавливает щит. В сетевых испытаниях у обоих одинаковые стандартные характеристики; коллекция даёт бонусы в одиночной игре.

Данные — локальные игровые сохранения, не защищённая онлайн-экономика. Очистка данных браузера удалит коллекцию. Монеты/предметы не продаются, не передаются и не имеют денежной ценности.

## Кооператив: что работает и что требует хостинга

Реализованы настоящий WebSocket-сервер и клиент: создание комнаты, код/ссылка-приглашение (включает адрес сервера), вход второго игрока и два отдельных испытания «Два огня» / «Зеркальный зал». Игроки должны одновременно удерживать две плиты одну секунду, собрать оба ключа, вместе подойти к выходу и нажать действие. Упавшего напарника можно поднять рядом с ним. Если упали оба — хозяин перезапускает испытание. После победы хозяин запускает следующее.

**GitHub Pages не запускает серверные процессы.** На публичной странице кооператив заработает только после размещения сервера на отдельном HTTPS/WSS-хостинге. По умолчанию постоянный публичный сервер НЕ настроен. Форма явно сообщает об этом и позволяет ввести его адрес. В локальном dev/live preview сервер запускается автоматически на том же порту, что и сайт — можно подключить два браузера.

При обрыве соединения прохождение останавливается, оставшийся игрок ждёт нового напарника. Автоматического восстановления текущего сетевого уровня нет. Комнаты живут в памяти одной серверной копии и удаляются после ухода всех игроков, рестарта сервера либо 10 минут без сообщений. Паузы в сети нет. Сервер рассчитывает движение/коллизии/плиты/урон; клиент не может прислать координаты или объявить победу. Есть ограничение размера/частоты сообщений, проверка Origin, heartbeat и остановка движения при устаревшем вводе.

### Локальный запуск

Node.js 22+:

```sh
npm ci
npm run dev
# http://localhost:4173
# WebSocket: ws://localhost:4173/socket
```

Сервер слушает `0.0.0.0`. Для телефона в одной сети открой HTTP-адрес компьютера; установка/offline требуют HTTPS. Для интернет-друзей нужны публичный адрес и TLS.

### Размещение сервера

Можно использовать любой хостинг Node.js/Docker с поддержкой WebSocket. Нужна **одна постоянно работающая копия**, не stateless/serverless function. Dockerfile включён:

```sh
docker build -t last-torch .
docker run --rm -p 4173:4173 \
  -e COOP_ORIGINS=https://vpn86156-ctrl.github.io \
  last-torch
```

- Старт без Docker: `npm ci --omit=dev && npm start`.
- `PORT` — порт (по умолчанию 4173), `COOP_ORIGINS` — разрешённые Origin через запятую, без завершающего `/`.
- `/health` — JSON health check; `/socket` — WebSocket. Reverse proxy должен передавать Upgrade/Connection и давать HTTPS/WSS.
- После размещения впиши `wss://ваш-домен/socket` в `src/coop-config.js` и опубликуй сайт. Или укажи адрес прямо в форме «Вдвоём» — он сохраняется только в этом браузере и включается в приглашение.
- Никакие токены/секреты не нужны в клиентском конфиге. Не помещай туда пароли.
- Встроенный сервер может отдавать сам сайт: тогда интерфейс и WebSocket используют один origin без ручного конфига.

## Проверки

```sh
npm test
npx playwright install --with-deps chromium
npm run test:browser
```

Для ограниченной Linux x64 среды без системного Chromium:

```sh
npm run test:browser:sandbox
```

Проверяются карты и тайники, экипировка и вероятности, сохранения, однократное получение награды, PWA/offline, портрет/ландшафт, удержание кнопок, реальные серверные соединения и два браузерных клиента одной комнаты. Некоторые сценарии ускоряют достижение выхода тестовой инструментализацией; доступность целей проверяется отдельно обходом карт. Результаты и снимки — в игнорируемой `test-results/`.

## Структура

- `src/engine.js`, `src/render.js`, `src/app.js` — одиночная игра и её интерфейс.
- `src/profile.js`, `src/features.js` — коллекция, кейсы, установка, награды.
- `src/coop-engine.js`, `server/rooms.mjs`, `src/coop.js` — сетевые правила, комнаты и клиент.
- `src/coop-config.js` — публичный адрес сервера для статического сайта.
- `scripts/serve.mjs` — статические ресурсы + WebSocket на одном порту.
- `sw.js`, `manifest.webmanifest`, `icons/` — устанавливаемая оболочка.

Canvas 2D, ES modules, CSS, Web Audio; нет внешних ассетов/шрифтов и сборки браузерного приложения. Единственная серверная runtime-зависимость — `ws`. История прежнего сайта сохранена в Git, его материалы не используются. Старые кеши `terraria-guide-v1-*` удаляются при активации worker; посторонние кеши и localStorage не очищаются.
