# TERRA Летопись — Android APK

**Результат проекта — устанавливаемое Android-приложение, не сайт, не PWA и не APK-ссылка на удалённую страницу.** Публикации GitHub Pages, service worker и офлайн ZIP в этой версии нет.

## APK

Публичный файл: `downloads/TERRA-Letopis-0.1.0.apk` (около 5 МБ). После локальной сборки: `artifacts/TERRA-Letopis-0.1.0.apk`.

Публичная сборка подписана заново. Она может не устанавливаться поверх ранее выданного частного APK с другой подписью. Удаление старого приложения удаляет его локальные записи.
Android 8.0+ (minSdk 26), targetSdk 35. ARM/ARM64/x86: APK не содержит нативных `.so`, используется системный Android WebView. Нужен обновлённый Android System WebView с поддержкой современных веб-стандартов.

Для установки открой APK на Android и разреши установку для выбранного файлового менеджера/браузера, если система запросит. Это не публикация в Google Play. Файл подписан уникальным локальным ключом, подпись проверяется `apksigner verify`.

Версия **0.1.0 — первая проверочная сборка**. APK скомпилирован и подпись проверена; интерфейс из самого APK тестируется в headless Chromium на автономном синтетическом origin. Это **не заменяет запуск на Android-устройстве/эмуляторе**: установка, системные отступы/клавиатура и жизненный цикл Activity требуют отдельной проверки на телефоне.

## Что внутри

- Ровно восемь разделов: Главная, Путь мира, Из моих ресурсов, Все крафты, Как получить, Все NPC, Сюжет Terraria, Мой дневник.
- 6186 предметов, 3655 рецептов, 3233 результата крафта, 26 основных NPC + 14 дополнительных.
- Локальные подлинные игровые атласы, изображения боссов, шрифты Manrope/Russo One.
- 11 этапов и декораций, последовательное открытие, подтверждение прохождения, защита от спойлеров, авторские истории Гида.
- Поиск, фильтры и страницы по 48 предметов; варианты рецептов, раскрываемое дерево с выходом/циклами и переходом к источникам.
- Инвентарь, проверка доступности ингредиентов с max-flow для пересекающихся групп, избранное.
- Дневник: создание, редактирование, удаление с подтверждением; цели из предметов/заданий.
- Данные остаются в локальном хранилище WebView между открытиями. Очистка данных/удаление APK удаляет записи. Автобэкапа и облачной синхронизации нет.

**Честные ограничения данных:** 5426 русских имён из игровых таблиц; 760 fallback-имён — английские. Неизвестные шансы и цены не выдумываются. Дополнительные условия исходника иногда показаны на английском с отметкой EN. Пример счастья NPC приблизительный, не полноценный планировщик. Отдельные ветви дерева показывают наличие ресурсов, но не распределяют общий запас между всеми соседними ветвями; точная проверка пересекающихся групп выполняется по списку выбранного рецепта.

## Архитектура и безопасность

Java Activity + встроенный React-интерфейс в **Android WebView**, не полностью нативные Android-экраны. Интерфейс компилируется в IIFE с локальными стилями. `src/` — внутренний интерфейс приложения; `ui/index.html` — шаблон для APK, а не опубликованный сайт.

Activity перехватывает `https://appassets.androidplatform.net/assets/...` и читает assets APK напрямую: DNS/сервер/HTTP-загрузка не используются. Другие запросы блокируются. Разрешения INTERNET нет, файловый доступ WebView отключён, JavaScript bridge отсутствует. Ссылки на wiki/GitHub только после жеста пользователя и подтверждения открывают внешний браузер. Кнопка Android «Назад» сначала закрывает диалог/меню, затем возвращает на главную, затем спрашивает о выходе.

## Сборка (Linux x86_64)

```sh
npm ci
npm run setup:android  # Python 3, pip, GitHub CLI gh с доступом к публичным репозиториям
npm run build
npm test
npm run test:ui
```

- `build:ui` собирает только внутренние assets в `build/ui`.
- `build:apk` компилирует Java, DEX, Android-ресурсы, выравнивает ZIP и подписывает APK.
- Скрипт SDK получает Android API 35 JAR из Sable/android-platforms и D8 из yaap/prebuilts_r8 по фиксированным Git blob SHA с проверкой хэша.
- JRE 21.0.8.2 — jdk4py/PyPI. AAPT2, javac и официальный apksigner упакованы в npm devDependencies с integrity lockfile. Они не попадают в APK.
- `android/` также открывается в Android Studio (AGP 8.9.2, Java 17+, SDK 35); предварительно выполни `npm run build:ui`. Gradle debug APK использует другой ключ и не заменяет сборку, подписанную локальным ключом.

### Ключ обновлений

Первый `build:apk` создаёт **неверсионируемые** `.android-signing/terra.p12` и `.android-signing/password.txt`. Они остаются приватными в рабочем каталоге и исключены из Git и APK. **Сохрани их отдельно перед будущим выпуском обновлений**, иначе новая подпись потребует удаления старого приложения с потерей его локальных записей. Не публикуй эти файлы. Можно указать `TERRA_KEYSTORE` и `TERRA_KEYPASS_FILE`, alias `terra`.

`artifacts/SHA256SUMS.txt` — контрольная сумма APK, `artifacts/apk-info.txt` — извлечённый манифест/информация пакета. Сборки и ключи не входят в Git.
