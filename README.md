# Космопилот

Космическая аркада для Android: кампания из восьми биомов и двадцати четырёх уровней со стражами, бесконечный полёт, прокачка корабля, кейсы с наградами и испытания. Игра запускается в горизонтальном положении, работает без интернета и не запрашивает разрешений. Все деньги и награды внутри игры игровые: покупок за реальные деньги нет.

## Установка

Скачайте **[Kosmopilot-1.3.0.apk](downloads/Kosmopilot-1.3.0.apk)** на телефон и откройте файл. Если Android попросит разрешить установку из выбранного источника, разрешение можно выдать в настройках системы. Минимальная версия — **Android 8.0**; нужен актуальный компонент Android System WebView. Контрольная сумма файла находится в `downloads/SHA256SUMS.txt`.

**Важно про обновление.** Версия 1.3.0 подписана новым ключом: ключ 1.1.0–1.2.0 был утерян вместе с рабочей средой, восстановить его нельзя. Поэтому обновить 1.2.0 поверх нельзя — Android требует удалить старую версию. Перед удалением откройте в 1.2.0 раздел **АНГАР → ПРОГРЕСС**, скопируйте код резервной копии, а после установки 1.3.0 восстановите его там же: кредиты, детали, улучшения, корабли и рекорд вернутся. Ключ версии 1.3.0 создан заново и лежит в том же каталоге `.android-signing/`; сохраните оба файла, чтобы следующие версии снова ставились поверх.

## Как играть

- Зажмите левую часть экрана и ведите пальцем: корабль последует за ним. Пушка стреляет сама.
- Уворачивайтесь от астероидов, комет и снарядов дронов. Количество делений корпуса зависит от улучшения «Корпус».
- Золотые звёзды дают очки, зелёный крест восстанавливает корпус, монеты и детали уходят в ангар. Если корпус целый, крест даёт дополнительные очки.
- Кнопка **«Волна»** справа уничтожает опасности рядом, бьёт по боссу и ненадолго защищает корабль; затем ей нужно время на перезарядку. Её можно нажать вторым пальцем, не отпуская управление.
- **Кампания** — 8 биомов по 3 уровня: два уровня с задачей и третий со стражем биома. Задачи бывают трёх типов: продержаться, разбить помехи или собрать звёзды. За уровень даётся от одной до трёх звёзд: одна за выполнение цели, вторая за быстрое прохождение или целый корпус, третья за полёт без единого повреждения. Следующий уровень открывается после предыдущего; когда закрыты все три уровня биома, открывается следующий биом.
- У каждого биома своя опасность: в туманности дрейфуют плазменные облака, в поясе обломков стоят контактные мины, в ледяном разломе морозят криогенные поля (корабль начинает хуже слушаться), в газовом омуте потоки сбивают с курса, на кладбище флота стреляют турели погибших кораблей, в короне солнца бьют вспышки на всю высоту экрана, в резонансных пещерах кристаллы отвечают залпом по кругу, а у сингулярности гравитация тянет корабль в ядро.
- **Страж биома** выходит через семь секунд после предупреждения, и у каждого свой характер: Страж Пустоты стреляет веером и телепортируется, Кузнец-Разрушитель сбрасывает раскалённый шлак, Криостраж морозит снарядами, Роевая Матка выпускает рой, Призрак Эфира уходит в фазу и пускает самонаводящиеся сферы, Солярис заряжает луч через весь экран, Оракл Бездны стреляет с упреждением, а Сердце Сингулярности притягивает корабль и бьёт кольцами с разрывами. Ниже половины здоровья любой страж впадает в ярость.
- Добивание стража — отдельное зрелище: время замедляется, броня распадается на осколки, гремит серия взрывов, экран трясётся.
- В бесконечном полёте биомы сменяются по кругу после каждого стража, а награды растут.
- За полёт начисляются кредиты и детали; дополнительные кредиты дают звёзды уровня и открытие нового биома. В **ангаре** они тратятся на улучшения пушки, корпуса, двигателя и волны; в **магазине** покупаются кейсы с деталями и обликами кораблей; в **испытаниях** выдаются награды за игровые достижения.
- Прогресс кампании, рекорд и звук сохраняются на устройстве. В разделе «ПРОГРЕСС» можно получить код резервной копии и восстановить его. При удалении игры локальные данные тоже удаляются.

Игру открывает короткая заставка: корабль пролетает через звёздный поток. Любое касание пропускает её. Музыка и звуки синтезируются на устройстве, их можно отключать отдельными кнопками.

Для проверки в браузере можно управлять стрелками или WASD и нажимать пробел для волны. На телефоне предусмотрено сенсорное управление; Android-кнопка «Назад» закрывает экран или вызывает паузу.

## Сборка

Исходники включают игровую симуляцию и интерфейс на Canvas/JavaScript, а также минимальную Android-оболочку с локальными ресурсами. Подключения к сети в приложении нет. Ниже приведены команды для Linux x86-64 с Node.js 20.19+ (ветка 20) или 22.12+, Python 3 с pip и `gh`:

```sh
npm ci
npm run setup:android     # скачивает закреплённый инструментарий в .local/
npm run setup:signing     # только один раз для нового ключа
npm run build:apk         # создаёт downloads/Kosmopilot-<версия>.apk
```

Ключ подписи и пароль лежат в `.android-signing/` и не входят в Git или APK. **Сохраните оба файла в защищённом месте**: Android принимает обновление установленной игры только с тем же ключом. При потере ключа потребуется удалить старую установку вместе с её данными. Для существующего ключа можно задать `KOSMO_KEYSTORE`, `KOSMO_KEYPASS_FILE` и, при необходимости, `KOSMO_KEY_ALIAS`. Скрипт не создаёт замену ключу автоматически.

Проверки:

```sh
npm test                  # симуляция, боссы, кампания, прокачка и экономика
npm run test:ui           # интерфейс, бой со стражем, ангар и офлайн-загрузка (собирает бандл)
npm run test:apk          # подпись, манифест, локальные ресурсы, выравнивание и хеш
```

Браузерный предпросмотр для разработки: `npm run build:web && npm run preview`. Это только предпросмотр той же игры, а не отдельная PWA или онлайн-сервис. Сведения об изображениях и шрифтах — в [ATTRIBUTION.md](ATTRIBUTION.md).
