# Terraria Guide

Русскоязычный фанатский путеводитель по Terraria 1.4.4+. React + Vite, адаптивная вёрстка, локальные изображения и шрифты — для работы приложения не нужны внешние CDN.

## Запуск

```bash
npm install
npm run dev
```

Сервер доступен на порту 5173. Production-сборка: `npm run build`, просмотр сборки: `npm run preview`.

## Возможности

- Четыре класса с оригинальными спрайтами и рекомендациями на четырёх этапах игры.
- 29 пошаговых руководств, фильтры, избранное и отметки прочтения.
- Трекер 16 выбранных боссов с тактиками и условиями призыва. Это не полный бестиарий всех боссов Terraria.
- Краткий пересказ предыстории мира и её связи с игровыми событиями.
- 20 советов, подборщик экипировки, поиск по гайдам, классам и боссам (Ctrl/Cmd + K).
- Прогресс, избранное и прочитанные руководства сохраняются в localStorage текущего браузера.

## Обновление «Мир экспедиций»

- Отдельная кнопка **«Мир экспедиций»** и обновлённый **«Атлас биомов»** в штабе открывают один и тот же интерактивный разрез: небо, поверхность, пещеры и Ад. **13 биомов**, обе океанские стороны кликабельны и приближаются к собственному берегу.
- Нажатие на местность плавно перемещает/масштабирует **тот же мир**, а не заменяет его страницей. «Весь мир» возвращает обзор; Escape работает с клавиатуры. Структура ландшафта детерминированная, без внешнего графического сервиса.
- В приближении — до трёх меток с оригинальными спрайтами: ресурс, существо и находка. Метки привязаны к точкам мира, открывают соответствующую часть досье. Внутри — выборка материалов и врагов с условиями, связь с архивом редкостей, бестиарием, тактикой босса и подготовкой к вылазке.
- **До хардмода / Хардмод / После Плантеры** меняют материалы, встречи, находки и часть изображения. До Стены плоти Освящение явно обозначено как будущее; эктоплазма появляется только на третьем этапе. У плодов жизни и добычи хлорофита отдельно указаны требования прогрессии, которые крупный переключатель не подменяет. Победы/инвентарь не проставляются.
- Фон меняется под местность; факелы мерцают. Уменьшение движения и ручное выключение анимаций учитываются. Доступны обычные кнопки биомов, клавиатура и разворачиваемая карта с нативным модальным диалогом; проверены телефоны 320/390 px.
- Новый раздел входит в поиск, восстановление раздела и проверяемый экспорт журнала. Все спрайты, текстуры и код карты входят в полную офлайн-копию, включая ещё не открытые биомы и этапы.
- **Не импорт `.wld` и не точный снимок игры:** это авторский составной учебный мир. Искажение и Багрянец показаны вместе для сравнения; координаты/залежи/сундуки условны. Списки — выборки для 1.4.4, не обещание всех врагов и предметов.

Реализация: `src/AtlasWorld.jsx`, `src/ExpeditionAtlas.jsx`, `src/atlasData.js`, `src/expeditionAtlas.css`. Десять новых проверок — `tests/atlas.spec.js`; полный набор после обновления — **97 тестов**.

- Поиск на русском/английском и по распространённым синонимам, поиск по ингредиентам, фильтр станков, количества, составы с заменами, жидкости/кладбище и другие условия. Клик по ингредиенту открывает его крафт; «Материал для» ищет его применения, включая допустимые замены; история возвращает прежние фильтры и страницу.

Данные и атлас входят в полную офлайн-копию; ошибка загрузки предлагает повтор, не сбрасывая прогресс.
- 12 дополнительных руководств: станки, травы, пруд, спавн, самоцветные деревья, грибной биом, хлорофит, проводка, мерцание, Королева слизней, Рыброн и Императрица. У каждого есть краткая памятка; новые руководства связаны с соответствующими этапами.
- В галерее **8 настоящих игровых референсов** со ссылками на исходные изображения и сохранёнными подписями. **9** рассчитанных планов комнат доступны отдельно; техническая сетка больше не заменяет главный визуальный пример. Материалы новых вариантов соответствуют их стилю, а внешний декор не выдаётся за учтённый расход.
- Оригинальные изображения всех ингредиентов алхимической корзины, включая руду, воду, рыбу и травы; существующий сумматор и сохранение не изменены.
- В помощнике фарма **12 проектов**: назначение, стадия игры, материалы, пять строительных шагов, ошибки, ссылки на механики. Авторские схемы с оригинальными текстурами можно увеличить и прокручивать на телефоне; это не скриншоты, не `.wld` и не обещание AFK-безопасности.
- Крафтовая страница включена в навигацию, общий поиск, возобновление прохождения и проверку экспорта/импорта. Новые карточки используют общую систему появления и настройку уменьшенного движения. Остальные 14 инструментов, профили и данные сохраняются.
- Источники, версии, преобразования изображений и воспроизводимый импорт: **[SOURCES.md](SOURCES.md)**. Обычная сборка не требует Python; он нужен только для повторной генерации каталога.

## Изображения и права

Terraria и оригинальная игровая графика принадлежат **Re-Logic**. Это независимый фанатский проект, не связанный с разработчиком.

- Спрайты получены из [bramaudi/terrabook](https://github.com/bramaudi/terrabook/tree/main/public/images). Изображения брони — игровые пиксельные изображения, без генерации или перерисовки. CSS `image-rendering: pixelated` сохраняет чёткие пиксели при увеличении.
- Файлы фона официальной вики получены из [BigBearKing/terraria-wiki-offline](https://github.com/BigBearKing/terraria-wiki-offline); эти дополнительные ресурсы не используются в интерфейсе.
- `hero.png` — отдельная сгенерированная атмосферная иллюстрация; это не скриншот игры.
- Шрифты Manrope и Press Start 2P установлены через Fontsource; лицензии находятся в соответствующих пакетах.
- `Terraria` — исходный файл из репозитория, сохранён без изменений.

Рекомендации по экипировке являются отправной точкой, а не единственными оптимальными билдами для любой сложности и версии игры.

## Обновление «Мой этап»

- Парящий оригинальный спрайт Зенита с вращением вокруг оси, светящимися орбитами и частицами. Нажатие открывает рецепт.
- 11 этапов прохождения, 44 сохраняемые цели, добыча и находки, 44 варианта рекомендаций экипировки (11 этапов × 4 класса), связанные гайды и тактики.
- 17 подробных досье боссов: 16 боссов основного трекера и Мозг Ктулху как альтернатива для Багрянца. Тактики включают арену, призыв, атаки, ошибки и награды.
- 17 руководств и 20 советов. Новые темы: зелья, рыбалка, заражение, хранилища, перековка, мобильность, темница, события, финальная подготовка и строительство.
- Эффекты появления при прокрутке и празднование победы. Кнопка «Эффекты» отключает движение, настройка сохраняется; системный `prefers-reduced-motion` также учитывается.
- Прогресс этапов хранится отдельно от босс-трекера. Никаких искусственных блокировок этапов и автоматического присвоения побед.
- 10 браузерных тестов, включая все этапы на мобильном экране, сохранение целей и класса, Зенит и режим уменьшенного движения.

- «Не выбрасывай» в каждом из 11 этапов, ссылки на карточки предметов и «Тайник Гида» со случайной полезной подсказкой (без выдачи добычи в игре).
- 16 сочетаний классовой брони на четырёх этапах. Картинки меняются в карточках, модальном билде, конструкторе и подробном маршруте. Экипировка ранних этапов больше не изображается финальным комплектом.

- Парящие находки, световые орбиты, мерцающие частицы, материализация брони, витрина легенд и визуальный прогресс архива. Все новые анимации учитывают переключатель эффектов и `prefers-reduced-motion`.
- Модальные окна удерживают фокус клавиатуры, скрывают фон от вспомогательных технологий и возвращают фокус при закрытии.
- 18 автоматических проверок: в том числе 16 комбинаций брони в карточках/окнах и в конструкторе, 44 сочетания этапа/класса маршрута, каталог, рецепты, сохранение, клавиатура, мобильный экран и отключение движения.

## Обновление «Живой мир»

- Общая система анимаций использует `IntersectionObserver` вместе с `MutationObserver`: появление карточек работает в гайдах, классах, боссах, советах, архиве, маршруте и мастерской, в том числе после фильтрации и смены этапа. Отдельно проверяется реальное изменение прозрачности/позиции при прокрутке.
- Зенит заметно парит и вращается двумя независимыми слоями. Тест сравнивает реальные матрицы преобразования и угол клинка в разные моменты, а не только название CSS-анимации.
- Настройки: ручной выключатель `terraria-motion` и режим `terraria-motion-mode` (`auto` / `full`). Авто уважает `prefers-reduced-motion`; явный полный режим позволяет пользователю включить движение. При сохранённом отключении или системном уменьшении движения показывается объяснение с кнопкой включения полного режима. Никакие пользовательские настройки не сбрасываются молча.
- Цветовая атмосфера меняется между разделами, в маршруте и в сюжетном чтении. Цвет слоя фона плавно интерполируется за 2,2 секунды; переходы отключаются в бережном режиме. Нет стробоскопов, резких вспышек или автоматического перелистывания.
- История переработана в 6 иллюстрированных глав с предыдущей/следующей главой, прямым выбором и содержанием. Преисподняя окрашивает окружение в тёмно-красный, поднимает угольки и показывает руины над лавой. Смена раздела возвращает его собственную атмосферу.
- `story-underworld.webp` и `story-corruption.webp` — сгенерированные атмосферные иллюстрации, не скриншоты; оригинальные спрайты боссов и персонажей наложены отдельно.
- Добавлены 24 самостоятельные редкие находки: оружие, питомцы, ездовые животные, добыча с мобов, редкие тайники и испытания. Всего 62 предмета. Новые категории «Добыча с мобов» и «Питомцы и тайники», источники и советы по фарму. Для Костяного ключа явно указана гарантия после сложной победы; для других предметов не обещается выдача после фиксированного числа попыток.
- 25 тестов Playwright, включая режим полного движения на устройстве с reduced-motion, реальные анимационные кадры Зенита, карточки после фильтрации, плавную смену цвета, мобильное чтение и все исходные проверки.

## Обновление «Штаб путешественника»

Все инструменты доступны из одной кнопки бокового меню, приглашения на главной и общего поиска. Сам штаб загружается отдельным JS-модулем. Существующие 11 этапов, 62 находки, 3 мастерские, брони и история сохранены.

- **Личный компас:** класс, сложность, здоровье, выбранный этап и определение этапа по отмеченным победам; до трёх незавершённых целей, актуальное снаряжение и ссылки на маршрут/боссов. Не требует необязательных боссов; для альтернативы Багрянца можно выбрать этап вручную.
- **Перед боссом:** 6 сохраняемых пунктов подготовки, ориентир здоровья, конкретные пробелы, арена и фазы. Не выдаёт процент победы и не распознаёт инвентарь.
- **Атлас:** 12 биомов на авторском вертикальном разрезе, причины посещения, опасности, связанные находки, враги и боссы. Ад меняет общую атмосферу на красную; уход из атласа восстанавливает фон. Это не карта сохранения.
- **Бестиарий:** 18 выбранных врагов с оригинальными спрайтами, биомами, условиями, тактикой и смыслом дропа; переход к правильному источнику фарма, включая находки без численных шансов.
- **Фарм:** отдельный сохраняемый счётчик каждой цели и выбранная сложность. Числа заявлены только для проверенных источников (Жезл раздора: 1/500 обычная, 1/400 Эксперт/Мастер; Костяной ключ: после победы над Стражем). Формула `1 - (1-p)^n` описывает независимые испытания, не систему накопления удачи. Почти 100% не округляется до обещания гарантии.
- **Сравнение:** 8 конкретных вариантов комплектов, точные оригинальные кадры брони/шлемов, защита, доступность, бонус и контекст выбора. Титановый барьер не перепутан со старым уклонением. Защита стрелкового титана — 34, святого стрелка — 35; ссылки на исходные таблицы приведены в интерфейсе.
- **Поселение:** 10 NPC, выбранная пара/биом, направленные предпочтения, предупреждения о скученности, отдельные проверки магазина и работающей сети пилонов. Неизвестные связи явно неизвестны; нет выдуманного точного множителя цен. Медсестра не объявляется продавцом пилонов.
- **Алхимия:** 8 рецептов с количеством 0–99, сохраняемая корзина, агрегированные ингредиенты и источники, ручные отметки сбора; 7 трав и условия цветения. Случайная экономия алхимического стола не уменьшает требуемый запас.
- **Календарь:** введённые вручную время, фаза Луны, дождь и прогресс мира; окна боссов, событий, существ, торговцев и цветения. Случайное событие/спавн никогда не объявляется гарантированным или прочитанным из мира.
- **Постройки:** 3 авторских клеточных схемы (15×9, 18×10, 17×10), посчитанные блоки, стены и мебель, пошаговая инструкция, легенда, условия жилья и Трюфеля. Это чертежи, не игровые скриншоты; счёт деталей не смешивается с рецептом сырья.
- **Зал трофеев:** 3 темы, настоящие оригинальные спрайты трофеев и одна явно подписанная эмблема Близнецов, полка редкостей из существующих отметок. Ничего не выдаёт в игре.
- **Приключения:** 22 задания четырёх направлений с границей этапа и дополнительными условиями, до 3 сохраняемых карточек, журнал завершения и отмена отметки.
- **Записки Гида:** 3 необязательные находки через доступные кнопки, подсказки и сохранение. Основные инструкции не заблокированы секретами.
- **«Я в игре»:** быстрая панель, крупный текст тактик/чек-листов, остановка декоративного движения, сохранение режима. Никакие важные инструкции не скрываются.
- **Эффекты:** отдельные переключатели появления, частиц, парения и постоянной атмосферы; общий выключатель и системное уменьшение движения сохраняют приоритет. Явный полный режим остаётся добровольным.
- **Перенос:** JSON `application=terraria-guide`, `schemaVersion=1`, не более 512 КБ. Только allowlist известных ключей и ID, проверка типов, размеров, диапазонов, дублей и опасных ключей. Предпросмотр и явное согласие до записи. Объединение списков (закреплённые карточки ограничены тремя, текущие приоритетны), логическое ИЛИ пунктов подготовки/маршрута, максимум счётчиков без двойного сложения или замена только перечисленных разделов; сторонние ключи не удаляются. Ошибка записи вызывает откат затронутых значений. Скачивание текущей копии доступно до применения. Сырой строковый ключ класса маршрута поддерживается.

## Обновление «Моя цель · справочник с собой»

1. **Одна текущая цель:** закрепление босса или этапа, быстрый возврат из любого раздела, арена/фазы/рекомендации и связанные материалы в одном плане. Отметки задач этапа общие с маршрутом; шесть ручных проверок общие с подготовкой в штабе. При смене босса их нужно перепроверять. Кнопка «Добавить зелья в корзину» не стирает уже запланированный запас. Победы никогда не выдаются автоматически.
2. **Продолжение:** последний раздел, инструмент штаба и позиция прокрутки сохраняются локально; домашняя кнопка возвращает туда. Временные фильтры и открытое модальное окно не восстанавливаются. «Назад» работает и в браузере, и в мобильной панели. Цель и точка продолжения включены в проверяемый экспорт/импорт; старые резервные копии по-прежнему принимаются.
3. **Поиск по содержимому:** полный текст гайдов, тактик, этапов, рецептов, условий цветения/появления, предметов и инструментов. Отдельные краткие ответы на вопросы про Узи, крылья, пилоны, Жезл раздора, Дары природы и броню призывателя ведут в соответствующую карточку. Это локальный индекс с нормализацией русских слов, не чат-бот и не обещание понимания любого вопроса. На телефоне поиск открывается отдельной кнопкой; Ctrl/Cmd+K сохранён.
4. **Полевые заметки:** 17 дополнений к тактикам с нюансами Эксперта, отдельно обозначенные ограничения Мастера, 10 доступных боевых замен редкому оружию (они не подменяют обязательные ингредиенты Зенита), 6 уточнений появления врагов. Важные карточки, рецепты и сравнения снабжены ссылками, целевой версией **1.4.4 без модов** и датой редакционной проверки текста **22.10.2026** — это не заявление о сверке с последним патчем. Условия Скелета-снайпера уточнены по [архивной статье](https://github.com/bramaudi/terrabook/blob/main/public/json/Skeleton%20Sniper.json): именно **Dungeon Slab Walls**, не Tiled Walls; знамёна не влияют на появление. Типы блоков для Элементаля хаоса сверены по [архиву](https://github.com/bramaudi/terrabook/blob/main/public/json/Chaos%20Elemental.json).
5. **Телефон и движение:** нижняя панель «Главная / Моя цель / Штаб / Назад», закреплённый селектор инструмента и возврат к разделам, увеличенные зоны нажатия. Новая отметка коллекции отправляет настоящий спрайт предмета на небольшую полку; выполненная подготовка оживляет символ экспедиции. Текст остаётся спокойным. Быстрый режим, отключённые соответствующие эффекты и уменьшенное движение выключают украшения, не инструкции. Типы карточек стабильны: запись позиции прокрутки или поиск не перемонтируют их и не перезапускают появление.
6. **Установка и офлайн:** manifest, собственные значки 192/512 и Service Worker без внешнего CDN. Поиск, штаб, текущая цель и инструменты загружаются отдельными модулями; полная офлайн-копия включает и ещё не посещённые разделы.

### Как взять сайт с собой

- Открой [публичный сайт](https://vpn86156-ctrl.github.io/TerarriaWiki/) по HTTPS. На главной нажми **«Установка и офлайн ↓»**, затем **«Скачать для офлайна»**; дождись надписи **«Полная офлайн-копия готова»**. Размер нынешнего снимка — около 6,6 МБ. Фоновая загрузка всего справочника без этого согласия не запускается.
- **«Установить на устройство»** вызывает системный запрос, если браузер его предлагает; иначе показывает подсказку для меню Chrome/Edge или Safari → «На экран Домой». Внешние страницы Wiki без сети не работают.
- Обновления не включаются автоматически: после полной загрузки нового снимка появляется **«Применить готовое обновление»**. Только эта кнопка активирует его и перезагружает текущую вкладку. Ошибка скачивания не уничтожает рабочую версию. Открытым соседним вкладкам сохраняются старые модули; при последующей активации без соседних вкладок удаляются только устаревшие кеши этого приложения, не чужие.
- Готовность проверяется по наличию **всех** файлов. Если браузер вытеснил кеш, кнопка загрузки явно восстанавливает его. Идентификатор снимка зависит и от ресурсов, и от кода Service Worker, чтобы обновление самого механизма кеша не перезаписывалось поверх активного снимка.
- Прогресс остаётся в **localStorage этого браузера**, а не в файлах офлайн-копии и не в аккаунте. Очистка данных браузера может удалить его. Для ценного прохождения скачай JSON в «Штаб → Настройки и перенос»; офлайн-снимок **не резервная копия прогресса**.

### Производственная проверка офлайна

`npm test` запускает не только dev-сервер, но и отдельную production-сборку на `http://localhost:8111/TerarriaWiki/` с тем же префиксом, что у Pages. **59 сценариев**: прежние 45, 9 проверок цели/поиска/мобильного интерфейса/настоящего движения и 5 проверок установки/офлайна. Офлайн-тесты действительно отключают сеть, открывают новую страницу, посещают все 14 инструментов и используют поиск; проверяют согласие на обновление, отказ повреждённого обновления, сохранение прогресса и чужого кеша, ремонт удалённого кеша и старый модуль соседней вкладки. Системную установку на конкретной модели телефона автоматизация не заменяет.

Перед публикацией `npm run pages:prepare` обновляет корневые `index.html`, `assets/`, `icons/`, `manifest.webmanifest`, `sw.js`, `offline-build.json`. Исходники manifest/значков находятся в `public/`, генератор атомарного кеша — `scripts/offline-build.mjs`. Сгенерированные артефакты не редактируются вручную.

## Обновление «Личный спутник прохождения»

### Один интерфейс вместо набора разрозненных панелей

- **Личная главная.** Первое посещение сохраняет знакомство с миром и оригинальный парящий Зенит. При наличии цели, прогресса или предыдущего посещения разделов главная показывает текущую цель/выбранный этап, до трёх незавершённых задач, выбранное прохождение, журнал побед и коллекции, связанные расходники, подходящее руководство и заметку. Повторяющиеся рекламные блоки убраны в раскрываемое «Открыть мир Terraria»; сами разделы не удалены.
- **Навигация по назначению.** Группы «Моё приключение», «Справочник», «Вдохновение», «Планирование». Старые «Инструменты» теперь явно называются **«Конструктор билда»**, чтобы не путать их со всеми 14 инструментами штаба. У текущего раздела есть видимый индикатор; сохранены поиск, нижняя мобильная панель, возврат к цели и браузерная история. Ссылка «К содержанию» доступна с клавиатуры.
- **Карта прогрессии.** 11 этапов на авторской схеме с оригинальными спрайтами, выделением выбранного этапа и вручную завершённых задач. На телефоне схема перестраивается без горизонтального скролла. Выбор точки ведёт сразу к её плану; из плана можно вернуться к карте. Переключатель **«Карта / Список»** сохраняет прежний доступный список. Это не карта файла мира, не автоматическое определение продвижения и не блокировка этапов.
- **8 необязательных веток:** рыбалка, Король слизней, Королева пчёл, поселения/пилоны, Королева слизней, Рыброн, Императрица, мастерская Зенита. Для подходящего этапа показываются причины посещения, подготовка и смысл награды со ссылкой на настоящее руководство. Рекомендованное место Рыброна на схеме не объявляется условием его появления.

### Инструкции, которые можно читать во время игры

- У **всех 17 руководств** есть короткий блок «Приготовь / Сделай / Не забудь», за ним полные исходные шаги.
- У **всех 17 досье боссов** — «До боя / В бою / После победы», связки «Что вижу → что делаю» и главная ошибка перед подробным разбором. Памятка не обещает перечислить все атаки всех сложностей. Значения HP явно подписаны как ориентир здоровья **персонажа**, не здоровье босса. Отдельно сохранены нюансы Эксперта/Мастера и источники.
- В конструкторе, модальных билдах и маршруте объясняется **почему** подходит стиль снаряжения, его слабость, доступный путь при нехватке предметов и момент следующего улучшения. Пояснения не называют послелунную броню условием первого финального боя; Ксено-посох явно связан с марсианами после Голема, броня жука — с добычей Голема.
- Четыре типа наглядных схем: **арена**, **покупка пилона и работа сети**, **слои мира**, **ветви рецепта Зенита**. Схемы — авторские пояснения, не скриншоты или копия мира. Оригинальные спрайты сохранены. Для арены дополнительно получена оригинальная [Heart Lantern](https://github.com/bramaudi/terrabook/blob/main/public/images/Heart_Lantern.webp); символ злого биома на карте — оригинальная [Shadow Scale](https://github.com/bramaudi/terrabook/blob/main/public/images/Shadow_Scale.webp), а не почти невидимый длинный спрайт червя.
- Текст крупнее и контрастнее в новых панелях; важные действия отделены от пояснений. При чтении руководств, истории, цели и модальных окон фоновые частицы приостанавливаются. Появление новых карточек работает через общую систему наблюдателей, режимы без движения/«Я в игре» сохранены.

### Заметки и несколько прохождений

Открой **«Мои прохождения»** через меню или карточку на главной. Можно хранить до **8 независимых прохождений**, создавать новые с названием, классом, сложностью и злым биомом, переименовывать текущее и возвращаться к любому предыдущему. Класс, сложность и здоровье текущего персонажа по-прежнему редактируются в «Штаб → Следующий шаг». Метаданные задаёт сам игрок; сайт не читает файлы Terraria.

**Старые отметки автоматически становятся первым прохождением при первом создании/переименовании.** До этого структура хранения остаётся прежней. Создание и переход требуют отдельного подтверждения; кнопка резервного копирования доступна до изменения. Настройки анимаций и быстрого режима общие и при смене мира не сбрасываются.

- Прогресс активного прохождения использует совместимые прежние `terraria-*` ключи. Список и снимки прохождений находятся в `terraria-runs`; текущий снимок обновляется из действительных рабочих ключей при переключении и экспорте.
- `terraria-notes` — обычная заметка и записи по ключам `boss:ID` / `stage:ID`. До **3000 символов на запись**, до **12 000 на прохождение**. Автосохранение происходит при вводе; статус ошибки оставляет текст доступным для копирования. Запись к одной цели синхронизируется между главной, планом и досье, а не создаёт три независимые копии.
- Переключение делает резервный снимок всех затрагиваемых значений, заменяет только ключи прохождения и откатывает изменения при ошибке записи. Посторонние данные браузера не затрагиваются. Неактуальная вкладка не может записать старое состояние поверх нового мира: записи проверяют ID и ревизию импорта, а соседние вкладки перезагружаются после смены прохождения. Приложение не поддерживает одновременную работу с разными прохождениями в разных вкладках одного браузера.
- Экспорт версии 1 теперь включает все прохождения и заметки с валидацией вложенных ID, ключей, количества и лимитов. Прежние файлы по-прежнему принимаются. Нельзя вложить архив внутрь архива или передать прототипные/неизвестные ключи. Лимит файла остаётся 512 КБ.
- **Объединение:** обычные отметки объединяются по прежним правилам; архив сохраняет текущие записи при совпадении ID и добавляет новые, не более восьми. Превышение числа прохождений или общего лимита заметок не обрезает их молча, а отклоняет импорт до записи.
- **Замена архива:** восстанавливается список из файла; отсутствующие рабочие поля его активного прохождения очищаются, чтобы не подмешивать старый мир. Без архива действует прежняя замена только переданных разделов. Перед применением всегда сохраняй текущую копию. Успешный импорт уведомляет другие вкладки о необходимости перезагрузки.
