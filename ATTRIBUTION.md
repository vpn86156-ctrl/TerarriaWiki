# Изображения и шрифты

- Обложка, космический фон, фоны ледяного и огненного секторов и изображение значка созданы с помощью генерации изображений Arena.ai специально для этой игры. Изображения не являются скриншотами реальной игры или фотографиями.
- Корабль, астероиды, кометы, дроны, стражи секторов, частицы, эффекты и элементы управления в самом игровом поле нарисованы кодом проекта. Звуковые эффекты синтезируются локально через Web Audio.
- **Manrope** — Manrope Project Authors; SIL Open Font License 1.1. Копия лицензии: `public/licenses/Manrope-OFL.txt`.
- **Russo One** — Jovanny Lemonad; SIL Open Font License 1.1. Копия лицензии: `public/licenses/Russo-One-OFL.txt`.

Копии обеих лицензий также включены в APK. Шрифты поставляются через npm-пакеты Fontsource и в игре загружаются из локальных ресурсов.
