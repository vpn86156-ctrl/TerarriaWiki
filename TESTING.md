- Java Activity скомпилирована под API 35; DEX включён в APK.
- `apksigner verify --verbose --print-certs`: успешно, подписи v2 и v3 действительны.
- Manifest/badging: minSdk 26, targetSdk 35, launcher Activity существует, разрешений нет.
- ZIP CRC: без ошибок. `resources.arsc` не сжат и выровнен по 4 байтам.
- Внутри APK находятся изображения, GIF, шрифты, данные и единый JS/CSS интерфейс.
- PWA-манифеста, service worker, удалённого стартового URL и офлайн ZIP в пакете нет.

## НЕ проверено

APK **не устанавливался и не запускался на реальном Android или Android-эмуляторе**: в среде их нет. Браузерные проверки не подтверждают поведение самого WebView на конкретном телефоне. Перед стабильным выпуском нужны проверки установки, Android Back/системного жеста, статус-бара/выреза/навигации, клавиатуры, поворота, убийства процесса, обновления поверх текущей версии и внешних ссылок на устройстве. Это первая проверочная сборка, не заявление о завершённом production-релизе.
