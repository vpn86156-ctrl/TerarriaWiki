# Проверки TERRA Wiki 0.3.0

Проверялся окончательный `artifacts/TERRA-Wiki-0.3.0.apk`, тот же файл скопирован в downloads.

- Размер: 5 419 155 байт.
- SHA-256: `f3b9a29db6c9c6cfaeb787d5665df946d2699e2615c8c2d5e1c2f8ce9a61e942`.
- Package ID: `io.github.vpn86156.terraletopis.design`.

- Android 8.0+, minSdk 26, targetSdk 35; universal APK без собственных native .so.

## Подпись и совместимость

`apksigner verify --verbose --print-certs` успешно проверил окончательный APK и опубликованный `downloads/TERRA-Letopis-Design-0.2.0.apk`.

**Их package ID и сертификат совпадают, versionCode повышен с 3 до 4.** Сертификат SHA-256: `66a4f1e3662541ae208d5f5c5e2c929665cae91967d0fa82268faba6901619df`. Следовательно, файл подготовлен как обновление «TERRA Дизайн» до «TERRA Wiki», а не третье отдельное приложение. Фактическая установка обновления на Android не проверялась.

Ключ localStorage `terra:chronicle:v1` не менялся. Данные 0.2.0 читаются с миграцией: старые два стартовых этапа требуют явного выбора, записи/рюкзак/избранное сохраняются. Историческая 0.1.1 имела другой package ID и сертификат; её данные автоматически не объединяются.

## Автотесты окончательного APK

```sh
npm run build
npm test
npm run test:ui
```

**11/11 тестов данных, пакета и сохранений; 17/17 браузерных сценариев пройдено.**

Первые 7 unit-тестов проверяют полный каталог 6186/3655/3233, NPC, уникальные ключи, подлинные атласы, ссылки ингредиентов/групп, max-flow, количества/выход рецептов, поиск/фильтры/спойлеры и APK. Четыре новых теста сохранений проверяют:

1. Новый мир: день 1, 0 завершённых глав, пустой рюкзак/дневник.
2. Старое сохранение с двумя этапами требует выбора и сохраняет записи/ресурсы/избранное/имя/день.
3. Реальный прогресс и уже сделанный выбор переживают восстановление.
4. Повреждённые данные не превращаются в два автоматически пройденных этапа.

Браузерные тесты извлекают assets именно из APK, открывают их на синтетическом HTTPS origin при **отключённой сети**. Незаявленные запросы, отсутствующие assets, ошибки JavaScript и console.error приводят к падению теста.

Проверены 17 сценариев:

## НЕ проверено

**Новый APK не устанавливался и не запускался на физическом Android или эмуляторе.** Пользователь прислал реальные телефонные скриншоты предыдущего выпуска; это не тест новой версии. Браузерные тесты не подтверждают реальное обновление пакета, сохранность данных при системной установке, форму иконки в конкретном лаунчере, системные отступы/вырез/клавиатуру, Android Back/жест, поворот Activity, убийство процесса и внешние ссылки. Проверки на телефоне нужны до стабильного production-релиза.

Известные ограничения дерева рецептов (общий бюджет соседних ветвей и раскрытия при вложенном диалоге), приблизительное счастье NPC и 760 EN fallback-имён не исправлялись этим выпуском.
