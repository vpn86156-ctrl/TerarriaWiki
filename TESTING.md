# Проверка сборки 1.4.0

Проверено 29 октября 2026 года:

- `npm test`: **41/41** проверка. Поверх прежних проверок симуляции, кампании, экономики и звука добавлены: переход стража в следующую фазу (телеграф, неуязвимость на время смены, новая фаза начинается с открытой слабой точки), прохождение всех восьми стражей до последней фазы и их разные смерти, урон по слабой точке (в 2,4 раза больше, чем по корпусу; при закрытой точке бонуса нет), а также две статические проверки исходников — каждый именованный импорт действительно существует в модуле-источнике и в `src/` не осталось отладочного вывода.
- `npm run test:ui`: **25/25** проверок в headless Chromium. Прежние 22 проверки (заставка, карта кампании, уровни и звёзды, ангар, кейсы, испытания, резервная копия, звук, касания, пауза, рекорд, поворот и четыре размера экрана) дополнены двумя: бой с Солярисом проходит все три фазы с телеграфом смены, открытой слабой точкой и сверхновой на смерти — при этом в консоли страницы не возникает ни одной ошибки; полёт в Газовом Омуте снимается на 1612×720 для контроля читаемости тумана.
- `npm run test:apk`: подписи APK v2/v3, идентификатор `io.github.vpn86156.kosmopilot`, versionCode 5 / versionName 1.4.0, минимальный SDK 26, горизонтальная ориентация, отсутствие разрешений, наличие и целостность ресурсов, выравнивание таблицы ресурсов.
- `npm audit`: известных уязвимостей не обнаружено на момент проверки.
- Воспроизводимость сборки: метки времени записей архива фиксируются, поэтому две сборки подряд из одних исходников дают одинаковый SHA-256. Файл в каталоге `downloads/` сверен с контрольной суммой.

**Что изменилось в бою со стражем (1.4.0).** Первые пять стражей дерутся в две фазы, Солярис, Оракл Бездны и Сердце Сингулярности — в три. Порог смены фазы отмечен засечкой на полосе здоровья. При переходе страж на 1,15 с замирает: вокруг сходится кольцо телеграфа, все его снаряды исчезают, урон не проходит. После смены у стража открывается слабая точка — ядро, клешня, глаз или вращающееся кольцо: попадание в неё стоит 2,4 обычных выстрела. Точка открывается по расписанию и сразу после каждой тяжёлой атаки. Смерть у каждого стража своя: осколки, ледяные иглы, шлак, растворение в пыли, сверхновая, кристаллы или схлопывание внутрь.

**Подпись.** Версия 1.4.0 подписана тем же ключом, что и 1.3.0, поэтому ставится поверх неё, сохраняя прогресс. Ключ 1.1.0–1.2.0 не сохранился, поэтому сертификат не совпадает с версией 1.2.0: обновление поверх невозможно, старую версию нужно удалить. Прогресс переносится кодом резервной копии: в 1.2.0 раздел **АНГАР → ПРОГРЕСС → СКОПИРОВАТЬ КОД**, в 1.4.0 там же **ВОССТАНОВИТЬ**. Код формата `kosmopilot-backup-v2` принимается, старые сектора превращаются в пройденные биомы.

APK `downloads/Kosmopilot-1.4.0.apk`: **1 035 510** байтов; SHA-256 `f5c14530f8e79273ec9b33ce7b6ddc518114fb062a383fab8721f9f5a1a452c3` (совпадает с `downloads/SHA256SUMS.txt`; две сборки подряд дали один и тот же хеш). Сертификат подписи тот же, что у 1.3.0: SHA-256 `0797adca1d9c143333fc03e1ddab472595b7e9f2706b1df4203c4017fea94335`, поэтому 1.4.0 ставится поверх 1.3.0.

Установка и запуск на реальном Android-устройстве или Android-эмуляторе **не выполнялись**. Проверки браузера не заменяют такую проверку.
