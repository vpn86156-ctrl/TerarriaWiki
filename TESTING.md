# Проверка сборки 1.2.0

Проверено 28 октября 2026 года:

- `npm test`: **30/30** проверок. Симуляция, движение, столкновения, бонусы, волна, перезарядка и результаты; предупреждение о страже, появление босса, фаза ярости ниже половины здоровья, распадение стража на осколки с цепочкой взрывов и замедлением времени; смена секторов в бесконечном полёте; влияние улучшений; экономика — стоимость улучшений, кейсы, испытания, расчёт награды за полёт, резервная копия и восстановление прогресса; звук — все эффекты безопасны без Web Audio, микшер и партия стража накладываются корректно, секвенсор музыки планирует шаги, звук и музыка глушатся раздельно.
- `npm run test:ui`: **21/21** проверок в headless Chromium: заставка с пролётающим кораблём и пропуском по касанию, карта полётов с закрытыми секторами, покупка улучшения и её влияние на следующий полёт, кейсы, испытания, восстановление прогресса, отдельные переключатели звука и музыки, начисление кредитов за полёт, а также настоящее эмулированное касание и два одновременных пальца, пауза, локальный рекорд, поворот экрана и четыре размера экрана.
- Бой со стражем проверен в браузере целиком дважды: полёт доведён до предупреждения и появления стража, в интерфейсе отмечена фаза ярости, после победы проигрывается распадение и только потом открывается экран результатов.
- Производительность отрисовки: после кэширования слоёв фона и световых спрайтов 5 секунд игрового времени (300 кадров) в программном режиме headless занимают около 5,8 с вместо 27,8 с. На устройстве с аппаратным ускорением запас по времени кадра больше, но измерение именно на реальном телефоне не проводилось.
- Продукционная сборка проверена полностью офлайн с загрузкой ресурсов через тот же локальный HTTPS-адрес, который использует Android-оболочка. Внешние запросы и сетевое соединение блокировались.
- `npm run test:apk`: проверены подписи APK v2/v3, идентификатор `io.github.vpn86156.kosmopilot`, versionCode 3 / versionName 1.2.0, минимальный SDK 26, горизонтальная ориентация, отсутствие разрешений, наличие и целостность ресурсов и выравнивание таблицы ресурсов. Сертификат совпадает с версией 1.1.0, поэтому обновление устанавливается поверх.
- `npm audit`: известных уязвимостей не обнаружено на момент проверки.

- Воспроизводимость сборки: две сборки подряд из одних исходников дают одинаковый SHA-256 (в коде фиксируются метки времени записей архива). Файл в каталоге `downloads/` сверен с опубликованной контрольной суммой.
