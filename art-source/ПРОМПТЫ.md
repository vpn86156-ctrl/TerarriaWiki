# Промпты для спрайтов «Заброшки»

Генерировать можно в любой нейросети. Всё, что нужно от картинки:

1. **Фон — яркая маджента `#FF00FF`.** Без неё скрипт не сможет вырезать объект автоматически.
2. **Один объект на кадр**, по центру, целиком в кадре, не обрезан краями.
3. **Квадратный PNG**, желательно 512×512 или больше (я сам уменьшу до 16–64 px).
4. **Стиль — пиксель-арт 16 бит**: чёткие «ступенчатые» пиксели, без размытия и без фотореализма.
5. **Никаких подписей, рамок, теней на фоне и интерфейса.**
6. **Имя файла — строго как в списке ниже** (скрипт берёт имя спрайта из имени файла).

К каждому промпту добавьте общий хвост (он одинаковый для всех):

```
16-bit pixel art game sprite, single object centered in frame, solid bright magenta #FF00FF
background, crisp hard pixel edges, no text, no labels, no UI, no drop shadow on the background,
three-quarter top-down view, muted grim palette, square image
```

Присылать можно пачкой, хоть все сразу: я сам разложу файлы по папкам и запущу нарезку.
